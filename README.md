# AI美业获客平台

专注为美发店、美容院、假发品牌提供AI全链条获客解决方案。

## 核心功能
- **AI获客引擎** - LBS精准获客，成本降低45%
- **AI成交助手** - AR虚拟体验，成交率提升60%
- **AI运营平台** - 智能排班分析，效率提升2倍
- **AI复购引擎** - 自动营销触达，复购率提升280%

## 技术栈
- 前端：Vue 3 + Vite + Tailwind CSS 4 + GSAP
- 后端：Express + Ollama AI
- 图表：Chart.js
- 轮播：Swiper

## 快速启动
```bash
npm install
npm run dev
```

## 定位
面向中国大陆市场的企业级SaaS获客平台，全站简体中文，百度SEO优化，完整响应式设计。
